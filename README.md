# webprog2023
Repository untuk mata kuliah Pemrograman Web semester ganjil 2023-2024
silahkan patuhi aturannya:
1. Setiap mahasiswa silahkan melakukan clone terhadap repository **main** dengan perintah di cmd atau terminal: **git clone https://github.com/Software-Engineering-ITTS/webprog2023.git**
2. Setiap mahasiswa setelah melakukan clone, harus membuat **branch** baru dengan format nama <nim>_<nama_pendek> caranya adalah dengan jalankan perintah berikut ini di **cmd** atau **terminal**:
   **cd webprog2023**
   kemudian lanjutkan dengan perintah:
   **git branch 123456789_fwp main**    /*misalkan nim = 123456789 dan nama = fwp*/
   kemudian perintah:
   **git checkout 123456789_fwp**
