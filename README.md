# webprog2023
Repository untuk mata kuliah Pemrograman Web semester ganjil 2023-2024
silahkan patuhi aturannya:
1. Setiap mahasiswa tidak boleh melakukan clone terhadap repository **main**
2. Setiap mahasiswa harus membuat **branch** baru dengan format nama <nim>_<nama_pendek> caranya adalah dengan jalankan perintah berikut ini di **cmd** atau **powershell** atau **terminal**:
   **git branch 123456789_fwp webku**    /*misalkan nim = 123456789 dan nama = fwp*/
   **git checkout 123456789_fwp**
